# 课程表Plus

一款帮助大学生管理课程、小组、大作业DDL和考试提醒的多端小程序/App。

## ✨ 核心功能

- 🗓️ 周视图课表：整页滑动翻周，自动吸附，支持上下滚动查看全天课程
- 📅 单双周/不规则周次：可勾选具体上课周数，非本周课程自动灰显
- 👥 小组管理：为每门课创建学习小组，动态添加成员
- 📋 大作业 & 考试提醒：按类型分类，设置截止时间，到点微信推送
- ⚙️ 灵活配置：自定义节次时间、学期起始日、当前周数
- 📱 多端复用：基于 uni-app，可编译为微信小程序、App、H5

## 🛠 技术栈

- 框架：uni-app (Vue 3)
- 后端/数据库：微信云开发（云数据库 + 云函数）
- 推送：小程序订阅消息
- 跨端适配：条件编译 + 云开发多端 SDK

## 🚀 快速开始

1. 克隆仓库并安装 HBuilderX
2. 在微信公众平台注册小程序，获取 AppID
3. 在 HBuilderX 中打开项目，修改 `common/cloud.js` 和 `App.vue` 中的云环境 ID 和自己的 AppID
4. 在微信云开发控制台创建 `courses`、`groups`、`tasks`、`user_settings` 四个集合
5. 运行到微信开发者工具，编译并预览
